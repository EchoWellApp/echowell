## Conventions

- **Wireframe reference**: screen name as in `WIREFRAMES.md`, then line numbers in `echowell-wireframes-v0.2.html` (for example "l.231–233"). Wireframe notes, bracketed placeholders and the notes toggle are not product content (D-108); where a row names one, the column says how it was resolved.
- **API endpoints** are under `/api/v1` (TRD 19); every one listed exists in `docs/api_reference/openapi.json`.
- **Test file short forms**: `Name.test.tsx` = `frontend/components/Name/Name.test.tsx`; `pages/x.test.tsx` = `frontend/tests/pages/x.test.tsx`; `unit/x.test.ts` = `frontend/tests/unit/x.test.ts`; `e2e/x.spec.ts` = `frontend/tests/e2e/x.spec.ts`. Backend tests are given as `path::test_name` from the repository root.
- **TST-061 / TST-064** apply to every backend row: every response produced in `tests/integration/api/` is validated against the OpenAPI schema, including `meta` (`tests/contract/response_validation.py`, `tests/contract/test_response_schemas.py`). Role access per endpoint is covered by TST-130 (`tests/security/test_auth_matrix.py::test_every_cell`).
- **Status**: "Traced" = every column filled with existing artefacts. "GAP" = at least one cell is MISSING; see Findings.
- §4.17 and §4.18 rows are finer-grained than the §4.16 rows for the same screens, so some artefacts appear twice. This is deliberate: FEAT-091-AC-08 asks for the §4.16 elements and the §4.17/§4.18 elements separately.
